# 笔记关联改变 (Note Attachment Tracker)

这是一个Obsidian插件，帮助用户管理与笔记相关的附件文件与文件夹。

## 主要功能

1. **关联文件夹管理**
   - 设置与笔记关联的文件夹相对路径
   - 支持自定义命名模式，如 `{$filename}_附件`
   - 笔记移动时，关联文件夹也会相应移动，保持与笔记的相对位置不变

2. **空文件夹清理**
   - 搜索无用的空附件文件夹
   - 支持自定义匹配模式
   - 提供单个或批量删除选项
   - **左侧工具栏快捷按钮**，一键搜索空文件夹

3. **回收站设置**
   - 可选择使用系统回收站或自定义回收目录

## 使用方法

### 关联文件夹设置

1. 进入插件设置
2. 在"关联文件夹设置"下添加文件夹命名模式
   - 使用 `{$filename}` 作为笔记名称的占位符
   - 例如：`{$filename}_附件`、`附件_{$filename}`等
3. 可以添加多个命名模式，并可分别启用或禁用

当笔记被移动或重命名时，符合命名模式的关联文件夹也会自动移动，保持相对位置不变。

### 空文件夹清理

1. 在"空文件夹清理设置"下添加要搜索的匹配模式
   - 例如：`_附件`、`/附件/`等
2. 点击左侧工具栏的文件夹图标按钮，或点击设置页面中的"搜索"按钮查找符合条件的空文件夹
3. 在弹出的列表中可以选择单个删除或全部删除

### 回收站设置

1. 可选择是否使用系统回收站
2. 如不使用系统回收站，可以指定自定义回收站文件夹的路径

## 安装方法

1. 在Obsidian中打开设置
2. 进入"第三方插件"
3. 禁用"安全模式"
4. 点击"浏览"并搜索"笔记关联改变"
5. 安装并启用插件

## 注意事项

- 插件对已存在的文件夹没有影响，只有在笔记移动或重命名后才会触发关联文件夹的移动
- 删除文件夹前请确认其内容确实无用，建议使用系统回收站方便恢复
- 匹配模式区分大小写
